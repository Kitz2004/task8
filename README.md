# Sales Dashboard Project

## Overview
This project involves creating an interactive sales dashboard using Power BI to analyze and visualize sales performance by product category, region, and time period. The dashboard helps business users quickly understand sales trends and make data-driven decisions.

## Dataset
- **File**: `Superstore_Sales.csv`
- **Columns**:
  - Order Date
  - Region
  - Category
  - Sales
  - Profit

## Dashboard Components
The dashboard includes the following visualizations:

1. **Monthly Sales Trend (Line Chart)**
   - Shows sales patterns over time
   - Highlights seasonal peaks and valleys

2. **Sales by Region (Bar Chart)**
   - Compares performance across regions
   - Identifies top-performing regions

3. **Sales by Category (Donut Chart)**
   - Displays proportion of sales by product category
   - Reveals which categories drive most revenue

4. **Interactive Filters**

## Key Insights

1. **Seasonal Patterns**
   - Highest sales occur in October-November (holiday season)
   - Summer months (June-July) show decreased sales

2. **Regional Performance**
   - West region leads in overall sales
   - Central region has most consistent performance

3. **Category Analysis**
   - Technology generates highest sales but has inconsistent profits
   - Furniture sales peak in late summer (back-to-school)

4. **Profitability**
   - Some high-sale Technology items have negative profits
   - Office Supplies maintain steady, modest profits

## How to Use
1. Open the `Superstore_Sales.pbix` file in Power BI Desktop
2. Interact with the dashboard by:
   - Selecting different regions in the filter
   - Hovering over charts to see detailed numbers
   - Using the date filters to focus on specific periods
